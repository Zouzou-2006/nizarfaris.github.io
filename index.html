03 PROJECTS

Agent Auditor — Spending Controls for AI Agent Payments

UBC 2026 Hackathon · Technical lead · Team of 4 · In progress

Preventive and detective controls for an AI agent that buys data in USDC on Solana devnet. The agent never holds the wallet key, so every payment must pass through a gateway I built: default-deny finance rules, human approval over $0.50, x402 pay-per-request payments with each order saved before money moves, and session/API-key auth on every action endpoint.

I proved on devnet that x402 payments can carry the order ID in the transaction memo, then added a guard that refuses to sign any quote whose memo doesn't match, so every gateway payment is traceable on-chain. I also designed the six-table Supabase schema (row-level security, realtime), built the live audit dashboard with a read-only Claude tool-use copilot, and set up CI for the team's 456-test suite. In the team's devnet demo, a clean purchase is matched and booked in about 9 s, and a payment sent around the gateway with a stolen key is flagged in about 1 s.

TypeScript Next.js React Solana x402 Supabase Claude API Vitest GitHub Actions
